# Histórico — ensayo real de $100 retirado

El producto y su enlace se retiraron de la página por solicitud del usuario,
para preparar el catálogo comercial.

El enlace usado fue https://mpago.la/2JmNHED. El usuario pagó con CuentaRUT de
BancoEstado. La operación 185920933158 pasó por revisión/en proceso y terminó
rechazada. El detalle comunicado fue: “Te protegimos de un pago sospechoso”.

No se acreditó el cobro ni se consideró una validación exitosa. El usuario
indicó que usó una ventana de incógnito; no está confirmado que esa fuera la
causa del rechazo. La recomendación del proveedor es usar el medio de pago y
dispositivo habituales del comprador.

No reutilizar este enlace para cobrar otro importe. La guía vigente de
lanzamiento es [PUBLICACION-COMERCIAL.md](../publicacion/PUBLICACION-COMERCIAL.md).
