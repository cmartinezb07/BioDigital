# Conceptos clave a dominar antes de vender (Fase 2)

| Concepto | Por qué se necesita antes de la primera visita |
|---|---|
| Business Model Canvas | Formaliza socios clave (NIC Chile, hosting, proveedor de capacitación), estructura de costos real (capex del equipo vs. costo por cliente) y flujos de ingreso. Sin esto el presupuesto queda ambiguo (ver riesgo #2 en [riesgos-criticos.md](riesgos-criticos.md)). |
| Value Proposition Canvas | Cruza dolores/ganancias del cliente con las features de cada paquete — evita vender features que no importan. |
| Pricing y unit economics | Costo real de entregar 1 paquete (tiempo del equipo + costo variable: dominio, hosting, fotos) vs. precio. Sin esto no se conoce el margen real por cliente. |
| Modelo de scoring de prospectos | Variables (rubro, ubicación, presencia actual en Google/RRSS, antigüedad, tamaño estimado), fuente de datos, y cómo se va a **validar** que el score predice cierre — sin validación es solo una lista con apariencia de rigor. |
| Embudo de ventas con tasas de conversión | Determina cuántos prospectos hay que contactar para cerrar 3-5 clientes. Regla gruesa de venta consultiva B2B bien calificada: 10-20% de cierre sobre reuniones agendadas. |
| Diagnóstico de presencia digital (producto-gancho) | Checklist estandarizado y repetible (completitud Google Business, presencia web, actividad en RRSS, reseñas) — no una evaluación ad-hoc distinta cada vez. |
| EDT/WBS y ruta crítica del propio proyecto | Las 7 fases del alcance son el WBS. Ruta crítica probable: cierre de venta → registro fotográfico → construcción → capacitación → acta de entrega, por cliente. |
| Gestión de riesgos | Qué pasa si un prospecto prioritario no responde, si un cliente no entrega contenido a tiempo (fotos/textos — el más común y casi nunca planificado), si un proveedor de IA no rinde a tiempo. |
| Aspectos legales/tributarios | SII es stakeholder declarado. Definir: ¿boleta de honorarios de un integrante? ¿a nombre de quién queda el dominio del cliente — si queda a nombre del equipo, no hay transferencia real? |
| Límites legales del levantamiento de datos públicos | Scraping masivo de Google Maps o Meta puede chocar con sus términos de servicio. Fuentes seguras: registros municipales de patentes, búsqueda manual, directorios públicos. |
| KPIs más allá del cierre | Tiempo de entrega por cliente, tasa de conversión real del scoring, satisfacción/NPS, referidos generados. |
